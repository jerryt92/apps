# jerryt92‘s Apps

Static bilingual website for Bamboo Cicada and PhotoTransfer.

## Local preview

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000/`.

## Routes

- `/` — app collection
- `/bamboo-cicada/`, `/bamboo-cicada/support/`, `/bamboo-cicada/privacy/`
- `/photo-transfer/`, `/photo-transfer/support/`, `/photo-transfer/privacy/`

The original app sites are copied into their own folders. Their styles and assets remain separate. Language preference is shared across all pages in this site.

The site is intended for GitHub Pages with `apps.jerryt92.top` configured as its custom domain.
